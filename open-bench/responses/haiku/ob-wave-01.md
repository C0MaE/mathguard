Step 1: Wave speed on the string.
v = sqrt(F / mu) = sqrt(70 N / 0.005 kg/m) = sqrt(14000) m/s = 118.3 m/s.

Step 2: Fundamental mode of a string fixed at both ends has wavelength lambda = 2 L.
f1 = v / (2 L) = 118.3 m/s / (2 * 0.65 m) = 118.3 / 1.30 = 91.0 Hz.

RESULT
f [fundamental frequency] = (1 / (2 L)) * sqrt(F / mu) = 91.0 Hz
