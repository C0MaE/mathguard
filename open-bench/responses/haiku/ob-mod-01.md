Step 1: Photon energy.
E_ph = h c / lambda = (6.626e-34 J s * 2.998e8 m/s) / 250e-9 m.
h c = 1.9865e-25 J m.
E_ph = 1.9865e-25 / 2.50e-7 = 7.946e-19 J.

Step 2: Convert to eV (1 eV = 1.602e-19 J).
E_ph = 7.946e-19 / 1.602e-19 = 4.960 eV.

Step 3: Einstein's photoelectric equation.
E_kin,max = E_ph - W_A = 4.960 eV - 4.3 eV = 0.660 eV.

RESULT
Ekin [maximum kinetic energy] = h c / lambda - W_A = 0.66 eV
