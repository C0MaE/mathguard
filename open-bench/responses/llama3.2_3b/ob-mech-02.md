To solve this problem, we'll use the concept of tension and acceleration in a pulley system. 

First, let's draw a free-body diagram of the system:

Block 1: 
- Weight: $m_1g$
- Tension: $T_1$

Block 2: 
- Weight: $m_2g$
- Tension: $T_2$

Since the pulley is massless and frictionless, the tension in the rope is the same on both sides. We can set up the following equations:

$$m_1g = T_1$$
$$m_2g = T_2$$

Since the tension in the rope is the same on both sides, we can set up the following equation:

$$T_1 = T_2$$

Now, we can use Newton's second law to find the acceleration of the blocks:

$$m_1a_1 = m_1g - T_1$$
$$m_2a_2 = m_2g - T_2$$

Since $T_1 = T_2$, we can substitute $T_1$ for $T_2$ in the second equation:

$$m_2a_2 = m_2g - T_1$$

Now, we can add the two equations to eliminate $T_1$:

$$m_1a_1 + m_2a_2 = m_1g + m_2g$$

Since $a_1 = a_2$ (the blocks are connected by the rope), we can substitute $a_1$ for $a_2$:

$$m_1a_1 + m_1a_1 = m_1g + m_2g$$

Combine like terms:

$$2m_1a_1 = m_1g + m_2g$$

Now, divide by $2m_1$:

$$a_1 = \frac{m_1g + m_2g}{2m_1}$$

Substitute the given values:

$$a_1 = \frac{(3\,\mathrm{kg})(9.81\,\mathrm{m/s^2}) + (2\,\mathrm{kg})(9.81\,\mathrm{m/s^2})}{2(3\,\mathrm{kg})}$$

Simplify:

$$a_1 = \frac{29.43\,\mathrm{kg\cdot m/s^2} + 19.62\,\mathrm{kg\cdot m/s^2}}{6\,\mathrm{kg}}$$

$$a_1 = \frac{49.05\,\mathrm{kg\cdot m/s^2}}{6\,\mathrm{kg}}$$

$$a_1 = 8.175\,\mathrm{m/s^2}$$

Now, we can find the tension in the rope:

$$T_1 = m_1g$$

Substitute the given values:

$$T_1 = (3\,\mathrm{kg})(9.81\,\mathrm{m/s^2})$$

Simplify:

$$T_1 = 29.43\,\mathrm{kg\cdot m/s^2}$$

$$T_1 = 29.43\,\mathrm{N}$$
