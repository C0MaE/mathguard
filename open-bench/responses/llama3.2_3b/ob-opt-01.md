To solve this problem, we can use the lens equation:

1/f = 1/do + 1/di

where:
- f is the focal length of the lens (10 cm)
- do is the object distance (15 cm)
- di is the image distance (which we want to find)

Rearranging the equation to solve for di, we get:

1/di = 1/f - 1/do

Substituting the values, we get:

1/di = 1/10 - 1/15

To add these fractions, we need a common denominator, which is 30:

1/di = 3/30 - 2/30
= 1/30

Now, we can take the reciprocal to find di:

di = 30 cm

Therefore, the image is 30 cm behind the lens.

RESULT
b [image distance] = 1/f - 1/do = 1/30 cm
di = 30 cm
